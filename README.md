# SQL Portfolio

This repository showcases SQL projects focused on querying, transforming and analysing data to support business intelligence, operational reporting and data-driven decision-making.

---

## Repository Overview

The projects in this repository demonstrate practical SQL skills used across analytics, engineering and business environments. They cover database design, query optimisation, reporting, data transformation and advanced analytical SQL techniques.

The portfolio emphasises writing clean, efficient and scalable SQL solutions that solve real-world business problems.
